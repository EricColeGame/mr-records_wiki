다음은 일반적으로 일어나는 순서와, 각 단계에서 무엇을 얻을 수 있는지입니다.

| 단계 | 일반적인 출처 | 얻을 수 있는 것 |
|---|---|---|
| 1. 프리미어 | 공식 인증 채널 | 최고 화질, 올바른 화면 비율 |
| 2. 언론 보도 | 엔터테인먼트 매체 | 글로 정리된 분석과 맥락 |
| 3. 반응 물결 | 크리에이터 커뮤니티 | 팬 해석과 이론 세우기 |
| 4. 재업로드 | 비공식 채널 | 종종 잘리거나, 음소거되거나, 미러링됨 |

진짜를 원한다면 1단계와 2단계에 머무르세요. 4단계는 잘못된 정보가 번식하는 곳입니다. 재업로드는 다시 인코딩되고, 저작권 때문에 오디오가 제거되며, 여러분이 보는 버전은 정작 중요한 프레임이 빠져 있을 수 있습니다.
