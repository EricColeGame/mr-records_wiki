## 典型的なリリースロールアウトの解剖

インディーであれメジャーであれ、ほとんどのリリースは認識できるリズムに従います。そのリズムを知っていれば、目の前の日付をどれだけ信用すべきかが分かります。

| フェーズ | 一般的なタイミング | 何を示すか |
|---|---|---|
| ティーザーまたは謎めいた投稿 | 4〜8週間前 | 何かが来る。まだ日付はない |
| タイトルと日付の発表 | 2〜6週間前 | 最初の公式確認 |
| プリセーブと予約の開始 | 1〜4週間前 | 配信システム上で日付が確定 |
| フォーカストラックまたはシングル | 1〜3週間前 | マーケティングの推進が始まる |
| プレスおよびプレイリストへの売り込み | 1〜2週間前 | 編集部のサポートが固まりつつある |
| リリース日 | 0日目 | プロジェクト全体が公開 |
| フィジカルの発送 | 数日〜数か月後 | レコードとグッズは別のスケジュールで動く |

特に重要なポイントが二つあります。第一に、プリセーブの公開は公式以外では最も強いシグナルです — ディストリビューターは通常、実体のないもののためにそうしたページを作りません。第二に、フィジカルフォーマットはデジタル日付の数週間後に届くのが常なので、発送予定日を Mr Records のリリース日と決して同一視しないでください。

タイミングは真夜中あたりで混乱することもあります。デジタルリリースは通常、特定の一つのタイムゾーンの真夜中に設定されるため、金曜日のリリースが西の地域のリスナーには木曜日の夜に現れることがあります。他の地域の人々と調整する場合は、推測せずに時刻を換算してください。

## 共有する前に Mr Records のリリース日を検証する方法

間違った日付を共有すると信用を失いますが、それは避けられます。見つけた日付はすべてこの簡単なチェックに通してください。

| シグナル | グリーンフラッグ | レッドフラッグ |
|---|---|---|
| 情報源 | 公式アカウントによる投稿 | リンクのないスクリーンショット |
| 文言 | 有効なリンク付きの「[日付] リリース」 | 「噂」「おそらく」「まもなく」 |
| クロスチェック | 二つの独立した情報源が一致 | 単一の匿名投稿 |
| カタログ項目 | 発表された日付と一致 | プレースホルダーの年または空欄 |
| アートワーク | 最終的なカバー、クレジット、トラックリスト | モックアップまたはファン制作のアート |
| 小売リスティング | SKU 付きの実際の商品ページ | 壊れたリンクまたは無効な予約 |

同じプロセスを、約2分で実行できるチェックリストにしたものがこちらです。

1. 最も早い公式投稿を見つけ、その引用ではなく全文を読む。
2. プリセーブまたは予約のリンクを開く。日付付きの実際のページが読み込まれれば、それは強い証拠です。
3. カタログデータベースの項目を一つ、公式発表と照合する。
4. レーベルがどのタイムゾーンを使っているかを確認し、自分のタイムゾーンに換算する。
5. 一致する二つの情報源が見つからなければ、その日付は「確定」ではなく「予想」と表示する。

ステップ5は多くの人が飛ばすものであり、あなたを守ってくれるものでもあります。

## Mr Records のリリース日を見逃さないためのアラート設定

| アラートの種類 | 設定方法 | 最適な用途 |
|---|---|---|
| フォロー＋通知ベル | 公式アカウントのアラートをオンにする | 最速の公式ニュース |
| プリセーブまたはプリアド | ストリーミングアプリでリリースを保存する | リリース日に自動追加 |

コミュニティの報告で繰り返し見られるテーマは、リリースを見逃す最も一般的な理由が突然の日付変更ではなく、静かに動いた日付だということです。リリースの約一週間前にプリセーブを再確認し、同じ日を指しているかを確かめましょう。リンクがリダイレクトしたり、日付が消えたりしていれば、それが早期警告です。

## Mr Records のリリース日が時々動く理由

延期は普通のことですし、そのほとんどには予測可能な原因があります。どれに当てはまるかが分かれば、待ち時間がどれくらいになりそうかも分かります。

| 原因 | 発生頻度 | 新しい日付にとって何を意味するか |
|---|---|---|
| サンプルまたは権利処理の問題 | 時々 | 数日〜数週間、時には無期限 |
| ミックスまたはマスタリングの修正 | かなりよくある | 通常は短期の延期 |

覚えておく価値のあるパターンはこれです。デジタルの延期は通常短く、告知されますが、フィジカルの延期は通常長く、静かです。レコードを買う場合は、発送予定日は常に Mr Records のリリース日とは別の出来事として扱ってください。

## FAQ

**Mr Records の公式リリース日はありますか？**
公式発表だけがそれを確定できます。レーベルやアーティスト本人からの日付入りの投稿が見つからなければ、アグリゲーターサイトが何度繰り返していようと、その日付は未確認として扱ってください。

**Mr Records のリリース日はどれくらい前に発表されますか？**
それは大きく異なります。数週間のリードタイムが与えられるプロジェクトもあれば、リリースのほんの数日前に発表されるものもあります。プリセーブリンク付きの完全な発表で2〜6週間というのはよくあるパターンですが、ルールではありません。

**なぜ Mr Records のリリース日は変わるのですか？**
権利処理の問題、マスタリングの修正、レコード製造の遅延、マーケティングのタイミングが通常の原因です。デジタルの日付は数日単位で動く傾向があり、フィジカルの日付は数か月単位で動くことがあります。

**Mr Records のリリース日は最初にどこで確認すべきですか？**
公式のレーベルまたはアーティストのチャンネルから始め、次にストリーミングのプリセーブページと [MusicBrainz リリースデータベース](https://musicbrainz.org/) のカタログ項目で確認してください。それらの情報源が一致すれば、自信を持って日付を共有できます。
